You are a process mining and process performance expert.

Your task is to select a final set of high-quality Process Performance Indicators (PPIs) from a set of candidates.

Use only the candidate information provided below.

# Goal
Select a small, diverse, and actionable set of PPIs that best supports process analysis and operational decision-making.

# Evaluation Criteria

Evaluate each candidate PPI according to the following criteria.

## Actionability
Prefer PPIs that help identify:
- bottlenecks
- delays
- inefficiencies
- compliance violations
- operational improvement opportunities

Avoid metrics that are purely descriptive or too generic.

## Relevance to Business Goal
Prefer PPIs that clearly measure progress toward the stated business goal.
Avoid PPIs that are only loosely related to the goal.

## Performance Dimensions
Each PPI measures one of these aspects:
- Time
- Quality
- Compliance
- Occurrences / Volume
- Cost / Resource usage
- Other

The final set should ideally cover multiple dimensions.

## Redundancy Rule
Two PPIs are redundant if they measure essentially the same process behavior, such as:
- two metrics measuring the same duration
- two metrics measuring the same compliance deviation
- two metrics measuring the same frequency

If redundant PPIs exist, prefer the one that is:
- more actionable
- more directly linked to the business goal
- easier to interpret.


# Selection Procedure

Perform the following steps:

Step 1 — Candidate Evaluation
Evaluate all PPIs for actionability and relevance.

Step 2 — Shortlist Creation
Create a shortlist of the strongest candidates.

The shortlist should contain approximately twice the number of PPIs that will be finally selected.

Remove candidates that are:
- weakly related to the business goal
- not actionable
- clearly redundant with stronger candidates.

Step 3 — Final Selection
From the shortlist, select at most {max_selected_ppis} PPIs that:
- maximize actionability
- strongly support the business goal
- cover multiple performance dimensions
- avoid redundancy.

# Constraints
- Use only these fields:
    - business_goal
    - business_goal_description
    - human_readable_ppi_definition
- Preserve the exact candidate_id.


# Guidelines:
- Explanations should be 1–2 sentences
- Mention actionability, relevance, or complementary coverage.
